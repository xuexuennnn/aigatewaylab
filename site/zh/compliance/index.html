合规

网关技术是把双刃剑：同样一套路由能力，既可以帮企业管好自有密钥，也可能被拿去转售消费级订阅。本页把界线白纸黑字写清楚。

承接的业务

  • 部署与运维只路由贵组织自有 API 密钥（BYOK，来自服务商官方 API 计划）流量的网关。
  • 在你自己的账号范围内提供虚拟密钥管理、配额、用量计量、路由与故障转移。
  • 安全加固、监控、备份与完整交接。

无论出价多少都不做的业务

  • 把消费级订阅（ChatGPT Plus、Claude Pro/Max、Gemini 消费版等）改造成可转售的 API 接入。
  • 账号拼池、配额共享、账号容量转售。
  • 绕过服务商的速率限制、并发上限或反滥用机制。
  • 提取、买卖或转移账号凭证。
  • 通过抓取私有 Web 界面来伪造 API 访问。

服务商对照表（API 接入方式）

以下摘要基于 2026-07-26 查阅的各服务商条款。条款随时可能调整，引用前请以官方原文为准。本表是工程合规摘要，不构成法律意见。
服务商官方 API（BYOK）经网关中继消费级订阅备注
OpenAI允许——平台 API 密钥不允许用于第三方转售中继平台条款将 API 用量绑定到账号持有者；消费级 ChatGPT 条款仅覆盖个人、非程序化使用。
Anthropic允许——控制台签发的 API 密钥不允许用于第三方转售中继商业条款明确区分 API 服务与消费级 Claude 应用。
Google (Gemini)允许——AI Studio / Vertex 密钥不允许用于第三方转售中继消费级套餐与 Cloud API 是条款相互独立的两种产品。
开放权重托管（Together、Fireworks、自托管 vLLM…）允许——标准 API 密钥或自有硬件 n/a对成本敏感的分层路由而言，这是最干净的一条路。

凡不在服务商官方计划覆盖范围内的接入方式，本站一律按「未验证」处理：不演示、不教学、也不会出现在 demo 里。
