合规

网关技术是双刃的。管理企业自有密钥的路由技术，同样可能被滥用于转售消费级订阅。本页白纸黑字写明：本工作室站在线的哪一边。

提供的服务

  • 部署与运维只路由你的组织自有 API 密钥（BYOK，来自服务商官方 API 计划）流量的网关。
  • 在你的账号范围内做虚拟密钥管理、配额、用量计量、路由与故障转移。
  • 安全加固、监控、备份与交接。

无论报酬多少都拒绝

  • 把消费级订阅（ChatGPT Plus、Claude Pro/Max、Gemini 消费版等）转成可转售的 API 接入。
  • 账号拼池、配额共享或账号容量转售。
  • 绕过服务商的速率限制、并发上限或反滥用系统。
  • 提取、买卖或转移账号凭证。
  • 抓取私有 Web 界面来模拟 API 访问。

摘要基于 2026-07-26 阅读的服务商条款。条款会变化；在依赖本表前请核对原文链接。这是工程合规摘要，不构成法律意见。
服务商官方 API（BYOK）经网关中继消费级订阅备注
OpenAI允许——平台 API 密钥不允许用于第三方转售中继平台条款将 API 用量绑定到账号持有者；消费级 ChatGPT 条款只覆盖个人、非程序化使用。
Anthropic允许——控制台签发的 API 密钥不允许用于第三方转售中继商业条款把 API 服务与消费级 Claude 应用区分开。
Google (Gemini)允许——AI Studio / Vertex 密钥不允许用于第三方转售中继消费级套餐与 Cloud API 是条款各自独立的两种产品。
开放权重托管（Together、Fireworks、自托管 vLLM…）允许——标准 API 密钥或你自己的硬件 n/a对成本敏感的路由分层来说是最干净的路径。

凡是不在服务商官方计划覆盖内的接入方式，这里一律按「未验证」处理：本站不演示、不写成教程、也不会在 demo 中启用。
